# Assalam Travel — сайт

Лендинг туроператора: умра и хадж из Западного Казахстана.
Статика, без сборщика и зависимостей — открывается и деплоится как есть.

## Структура

```
index.html          собранный сайт (не редактировать вручную — перезапишется)
404.html            страница «не найдено»
robots.txt          разрешение для поисковиков
vercel.json         заголовки кеша и безопасности для Vercel
build.sh            сборка
serve.ps1           локальный сервер для проверки

src/
  body.html         ← ВЕСЬ КОНТЕНТ РЕДАКТИРУЕТСЯ ЗДЕСЬ
  head.html         <head> сайта (title, meta, og, шрифты)
  artifact-head.html <head> для превью-артефакта

assets/
  css/styles.css    стили и дизайн-токены
  js/i18n.js        казахский словарь
  js/main.js        конструктор подбора, меню, счётчики, отправка в WhatsApp
  img/              фотографии, логотип, favicon, og-превью
  img/poster/       первые кадры роликов (видно до нажатия Play)
  video/            8 роликов «как проходит умра» + 4 видеоотзыва

source/             исходники, которые не публикуются:
                    оригинал логотипа от клиента и неиспользованные картинки
.build/             сборка для превью-артефакта и запасные видео (в git не идёт)
```

## Как править

1. Меняете текст в `src/body.html` (или стили в `assets/css/styles.css`).
2. Запускаете сборку:

```bash
bash build.sh
```

Пересоберутся `index.html` и `.build/artifact.html`. Сборка заодно проверяет,
что все строки переведены на казахский и все картинки лежат на месте.

Посмотреть результат локально (нужен именно сервер — иначе видео не играют):

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Откроется на `http://localhost:8080/`.

## Деплой на GitHub + Vercel

Репозиторий уже создан и первый коммит сделан, ветка `main`. Осталось три шага.

**1. Проверьте, чьим именем подписаны коммиты** (сейчас стоит имя из почты —
поменяйте, если нужно другое):

```bash
git config user.name "Ваше имя"
```

**2. Создайте репозиторий на GitHub и отправьте код.**
Репозиторий лучше сделать **приватным**: в нём лежит `CONTENT.md` со списком
того, что ещё заглушка, — этому не место в публичном доступе.

```bash
gh repo create assalam-travel --private --source=. --remote=origin --push
```

Без `gh` — создайте репозиторий руками на github.com и выполните:

```bash
git remote add origin https://github.com/ВАШ_АККАУНТ/assalam-travel.git
git push -u origin main
```

**3. Подключите Vercel.** На vercel.com → Add New → Project → выбрать репозиторий.
Настройки определятся сами, менять ничего не нужно:

| Поле | Значение |
|---|---|
| Framework Preset | Other |
| Build Command | пусто |
| Output Directory | пусто (корень репозитория) |
| Install Command | пусто |

Дальше каждый `git push` в `main` обновляет сайт автоматически.

Альтернатива без GitHub — залить папку напрямую:

```bash
npx vercel --prod
```

### Что уже настроено

- `vercel.json` — заголовки кеша (картинки и видео на 30 дней, css/js на час,
  html без кеша) и базовые заголовки безопасности;
- `.vercelignore` — на хостинг уезжают только `index.html`, `404.html`,
  `robots.txt` и папка `assets`. Исходники, README и `serve.ps1` — нет;
- `404.html` — страница «не найдено» в фирменном стиле.

### Что доделать после подключения домена

В `src/head.html` адреса og-превью относительные. Часть сервисов (некоторые
мессенджеры, Slack) не умеет их разворачивать, поэтому после подключения домена
замените их на абсолютные и добавьте canonical:

```html
<meta property="og:url"   content="https://ваш-домен.kz/">
<meta property="og:image" content="https://ваш-домен.kz/assets/img/og.jpg">
<link rel="canonical"     href="https://ваш-домен.kz/">
```

Затем `bash build.sh` и `git push`.

### Про видео

Ролики лежат в репозитории обычными файлами и весят ~52 МБ. Это в пределах
лимитов GitHub и Vercel, но:

- **не переводите их на Git LFS** — Vercel отдаёт LFS-файлы как текстовые
  заглушки, и видео перестанут играть;
- если роликов станет заметно больше, перенесите их на внешний хостинг
  (Cloudflare Stream, Bunny, YouTube без брендинга) и подставьте ссылки
  в `src/body.html`;
- каждый ролик грузится только когда карточка появилась на экране
  (`preload="none"`), до этого видно постер из `assets/img/poster/`.
  Одновременно играют максимум три — чтобы не грузить слабые телефоны.

## Два языка: РУС / ҚАЗ

Переключатель стоит в шапке. Выбор запоминается в браузере — при следующем заходе
посетитель сразу видит свой язык.

**Как устроено.** Русский лежит прямо в разметке — так он попадает в поиск и
отрисовывается мгновенно, без «моргания». Казахский хранится в словаре
`assets/js/i18n.js`. При загрузке скрипт запоминает русские строки со страницы,
поэтому дублировать их в словаре не нужно: переключение работает в обе стороны.

**Как добавить или изменить текст:**

1. В `src/body.html` повесьте на элемент атрибут с ключом:
   ```html
   <p data-i18n="about.lead">Русский текст</p>
   ```
2. В `assets/js/i18n.js` добавьте казахский перевод с тем же ключом:
   ```js
   'about.lead' : 'Қазақша мәтін',
   ```
3. `bash build.sh`

Для плейсхолдеров — `data-i18n-ph="name"` (ключ в словаре будет `ph.name`),
для `alt` картинок — `data-i18n-alt="photo.alt"`.

⚠️ **Важное правило:** ключ вешайте на элемент, внутри которого нет кнопок и полей
с обработчиками — при переключении содержимое элемента перерисовывается. Поэтому,
например, у кнопок конструктора ключ стоит на самой кнопке (её обработчик
сохраняется), а не на родительском блоке.

Строки, которые подставляет скрипт (подсказки об ошибках, текст сообщения в
WhatsApp, кнопка «Далее»), лежат в том же файле в объекте `JS_STR`.

**Проверить, что ничего не забыли:**

```bash
grep -o 'data-i18n="[^"]*"' index.html | sed 's/data-i18n="//;s/"//' | sort -u > /tmp/used.txt
grep -oE "^\s+'[A-Za-z0-9._]+'\s+:" assets/js/i18n.js | sed "s/[' :]//g" | sort -u > /tmp/have.txt
comm -23 /tmp/used.txt /tmp/have.txt
```

Команда выведет ключи без перевода. Сейчас список пустой — переведены все 231.

## Дизайн-система

Палитра выведена из логотипа — тёмно-синий бейдж и золотой градиент.

| Токен | Значение | Роль |
|---|---|---|
| `--ink-800` | `#0A1526` | основной фон (цвет бейджа логотипа) |
| `--ink-900` | `#050C16` | глубокие секции, футер |
| `--gold` | `#E8BF6B` | акцент, кнопки, орнамент |
| `--gold-lt` | `#FBEFCF` | блики в градиенте |
| `--sand` | `#F4EFE4` | светлые «дневные» секции |

Шрифты: **Manrope** (интерфейс и текст), **Cormorant Garamond** italic (акцентные слова
в заголовках), **Amiri** (арабская каллиграфия).

Секции чередуются «ночь / день»: тёмные несут эмоциональную часть (герой, вылеты,
обряды), светлые — практическую (что входит, отзывы, вопросы).

## Как работают заявки

Бэкенда нет. Все формы и кнопки «Забронировать» собирают сообщение и открывают
**WhatsApp** компании (`+7 777 829 9099`) с уже готовым текстом — так эти агентства
и работают на практике.

Номер задаётся одной константой в начале `assets/js/main.js`:

```js
var WA = '77778299099';
```

Если позже понадобится приём заявок на почту или в CRM — форму легко переключить
на Formspree/Telegram-бота, менять надо только обработчик `#leadForm`.

## Логотип

На сайте стоит **настоящий фирменный логотип клиента**. Сам рисунок не менялся:
не перерисовывался, не перекрашивался, обводки и градиент — оригинальные.

| Файл | Что это | Где используется |
|---|---|---|
| `assets/img/logo-full.png` | Локап (знак + ASSALAM TRAVEL), 560×240, прозрачный фон, 97 KB | шапка и футер |
| `assets/img/favicon.png` | Только знак, без текста, 256×256 | вкладка браузера, иконка на телефоне |
| `assets/img/logo-original.png` | **Исходник как прислали**, 3508×2480, 600 KB | не используется, хранится как мастер-файл |
| `assets/img/logo.svg` | Векторный запасной знак | подставляется, только если PNG пропадёт |

Из исходника убран **пустой холст** вокруг рисунка — он занимал 73% кадра, из-за чего
логотип в шапке получался высотой 14 пикселей. Обрезаны только прозрачные поля;
пиксели самого знака не тронуты. Исходник целиком лежит рядом в `logo-original.png`.

**Размеры** задаются в `assets/css/styles.css`:

```css
.brand__logo{height:58px}       /* шапка */
.brand__logo--lg{height:72px}   /* футер */
```

Если понадобится заменить логотип — просто положите новый файл под именем
`logo-full.png` и пересоберите. Разметка его никак не обрабатывает, только задаёт высоту.

### Запасной знак

Если файл логотипа вдруг не загрузится, на его месте автоматически появится векторный
знак (`brand__fallback` в `src/body.html`), чтобы страница не выглядела сломанной.
Градиент `#alg` и маска `#alCut` для него объявлены один раз в `<defs>` в начале `src/body.html`.
